# Student Performance Prediction

## Project Overview
This project uses machine learning to predict student final marks based on student performance data.

## Dataset
- Number of student records: 500
- The dataset contains student performance information used for training and prediction.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Machine Learning
- Google Colab

## Project Results
- Model evaluation metric: R² Score
- R² Score: 0.909
- Predicted Final Marks: 80.38

## Project File
- `Student_Performance_Prediction.ipynb` – Google Colab notebook containing the complete project.
